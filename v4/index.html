병리 판독 블라인드 평가

발급받은 판독자 코드를 입력해 주세요. 같은 코드로 다시 접속하면 이어서 진행됩니다.

데모 모드: 서버가 설정되지 않아 응답이 이 브라우저에만 저장됩니다.

평가 안내

총 50문항입니다. 각 문항에는 기준 슬라이드 1장과 검색 슬라이드 10장이 제시됩니다. 검색 슬라이드를 한 장씩 기준 슬라이드와 비교하여 유사도를 1-5점으로 평가해 주십시오.

  • 모든 슬라이드에는 장기와 암종 정보가 함께 표시됩니다. 한 문항 안의 슬라이드는 모두 같은 장기·암종입니다.
  • 각 슬라이드는 전체 저배율 이미지와 고배율(약 20×) 패치 4장으로 제공됩니다. 전체 이미지 위의 숫자는 각 패치의 위치입니다.
  • 고배율 패치는 종양 영역 안에서 형태가 서로 다른 대표적인 조직 유형 4가지를 1장씩 보여드리며, 종양 영역에서 많이 나타나는 유형부터 순서대로 배치했습니다.
  • 이미지를 클릭하면 기준 슬라이드와 나란히 놓고 확대해 비교할 수 있습니다(마우스 휠: 확대, 드래그: 이동).
  • 검색 슬라이드의 순서는 무작위이며 의미가 없습니다. 각 슬라이드는 다른 슬라이드와 비교하지 말고 기준 슬라이드와만 비교해 독립적으로 평가해 주십시오.

평가 질문

기준 슬라이드의 종양과 비교했을 때, 해당 검색 슬라이드의 종양이 조직학적 성장·분화 패턴, 세포 및 핵의 형태, 세포 밀도 등에서 얼마나 유사합니까?

(제공된 전체 이미지와 고해상도 patch의 형태학적 특징을 종합적으로 고려해 평가해 주십시오.)
